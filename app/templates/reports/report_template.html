2.2 Equações Fundamentais de Curto-Circuito

a) Corrente Trifásica Máxima — Icc3φ

IEC 60909-0:2016, equação (29) — Corrente de curto trifásica máxima (simétrica, kA eficaz):
I"k3 = (c × Un) / (√3 × |Z1,acum|)

onde: c = fator de tensão (1,10 para máxima); Un = tensão nominal fase-fase [kV]; Z1,acum = impedância de seq. positiva acumulada da fonte até o ponto de falta [Ω].

b) Corrente Bifásica — Icc2φ

IEC 60909-0:2016, eq. (32) — Corrente de curto bifásica (sem terra, simétrica):
I"k2 = (√3/2) × I"k3 ≈ 0,866 × I"k3

c) Corrente Monofásica — Icc1φ (neutro aterrado)

IEC 60909-0:2016, eq. (33) — Corrente de curto monofásica:
I"k1 = (√3 × c × Un) / (|Z1 + Z2 + Z0|)

onde: Z0 = impedância de seq. zero acumulada. Válido apenas para sistemas com neutro aterrado. Z2 = Z1 (componentes simétricas).

d) Corrente de Pico — ip (componente CC)

IEC 60909-0:2016, eq. (52) — Corrente de pico máxima (assimétrica):
ip = κ × √2 × I"k3
IEC 60909-0:2016, eq. (73) — Fator de assimetria κ:
κ = 1,02 + 0,98 × e−3/(X1/R1) ; 1,0 ≤ κ ≤ 2,0

O fator κ depende da relação X/R no ponto de falta. Para X/R = 10: κ ≈ 1,82. Para X/R → ∞: κ → 2,0.

e) Corrente Acumulativa (rede radial)

Acumulação sequencial de impedâncias (topologia radial):
Zacum,n = Zfonte + Zseg1 + Zseg2 + ... + ZsegN Zseg,linha = (R1 + jX1) × L [R em Ω/km, L em km] Zseg,trafo = (%Z/100) × (Un2/Sn) [Ω] ; X/R = 10 (assumido) Zfonte = Un2 / Scc,conc [Ω] (X/R = 10 — distribuição MT)

A corrente de curto DIMINUI conforme nos afastamos da fonte. Icc máximo = no ponto mais próximo da fonte.

f) Curvas de Proteção Inversa — IEC 60255-151

IEC 60255-151:2009 — Equação geral das curvas inversas temporizadas:
t = TMS × β / (Mα − 1) ; M = I / Ipickup NI: α = 0,02 ; β = 0,114 (Normalmente Inversa) VI: α = 1,00 ; β = 13,5 (Muito Inversa) EI: α = 2,00 ; β = 80,0 (Extremamente Inversa) LI: α = 1,00 ; β = 120,0 (Longa Inversa)
